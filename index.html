PART I

Privacy Policy

This tool is a single-operator automation script. It has no public sign-up, no user accounts of its own, and no visitors other than its operator. This policy explains, plainly, what it touches and why.

1.1Overview

Kids English Shorts Auto-Poster is a local command-line tool built for one person — its operator — to schedule and publish short-form English-learning videos for children (phonics lessons featuring the character “Momo”) to the operator’s own YouTube and TikTok accounts. It is not distributed to other users and does not process data belonging to anyone other than the operator and the operator’s own connected accounts.

1.2Data the tool collects

CategoryExamplesSource
Video contentMP4 files, narration audio, subtitle files, illustration imagesGenerated locally by the operator
Video metadataTitle, description, tags, privacy settingAuthored by the operator
OAuth credentialsClient ID/secret, access & refresh tokens for YouTube and TikTokIssued by Google and TikTok when the operator authorizes the tool
Creator infoTikTok username, avatar, posting permissions (via Query Creator Info)TikTok API, returned about the operator’s own account only

1.3How this data is used

  • Uploading and publishing the operator’s own videos to the operator’s own YouTube channel and TikTok account.
  • Reading the operator’s creator posting permissions and duet/stitch/comment settings before a post, so the request TikTok receives matches what the operator’s account currently allows.
  • Refreshing expired access tokens automatically so re-authorization isn’t required for every post.

The tool does not use this data for advertising, profiling, analytics resale, or any purpose beyond publishing the operator’s own content.

1.4TikTok platform data

Where the tool integrates with TikTok, it accesses only what the Content Posting API exposes about the authorizing account: basic profile info (username, avatar) and creator posting settings (privacy level options, duet/stitch/comment toggles, branded-content status). It does not read the operator’s TikTok inbox, followers, or any other account’s data, and it does not use TikTok data to train models of any kind.

1.5Storage & retention

All credentials and video assets are stored locally on the operator’s own machine, inside the project’s secrets/ and output/ directories. Nothing is transmitted to a third-party server operated by anyone other than YouTube (Google) or TikTok themselves — the destinations the operator explicitly authorized. Tokens persist until the operator revokes them from their Google or TikTok account settings, or deletes the local token files.

1.6Sharing & disclosure

Data is not sold, rented, or shared with any party beyond the platforms the video is being published to (YouTube, TikTok) as a direct result of the operator’s own publish action.

1.7Note on children’s content

Made for kids, not by kids The videos this tool publishes are educational content for a young audience (ages 3–7). The tool itself collects no data from viewers or children of any age — it has no comment system, no viewer accounts, and no analytics collection beyond what YouTube/TikTok natively report to the video owner. Videos are marked as made-for-kids on YouTube where applicable.

1.8Your rights, as the operator

Because the operator is the sole subject of this policy, all rights are exercised directly: revoke YouTube access at myaccount.google.com/permissions, revoke TikTok access from TikTok’s app settings, or delete local token files to immediately stop the tool from posting.

1.9Contact

Questions about this policy can be sent to co.psg0316@gmail.com.

PART II

Terms of Service

Plain-language terms governing use of the tool by its operator.

2.1Acceptance

By configuring API credentials and running this tool, the operator agrees to these terms and to the terms of service of each connected platform (YouTube/Google, TikTok).

2.2What the tool does

The tool assembles short videos from operator-supplied narration, illustrations or AI-generated video clips, and subtitles, then publishes the finished file to the operator’s own YouTube and/or TikTok account using each platform’s official upload API. Every publish action is initiated directly by the operator running the script; nothing posts on a hidden schedule without the operator’s command.

2.3Connected accounts

The operator authorizes the tool to act on their own YouTube and TikTok accounts via OAuth. The tool never requests or stores the operator’s platform password — only the access tokens each platform issues after the operator signs in directly on that platform’s own login page.

2.4Acceptable use

  • The tool is used only to publish content the operator created or has full rights to publish.
  • Content published must comply with YouTube’s and TikTok’s respective Community Guidelines, including rules for content directed at children.
  • The tool is not used to post on behalf of any account other than the operator’s own.

2.5Availability

This is a personal-use script, not a hosted service. It has no uptime commitment and depends on the continued availability of the YouTube Data API and TikTok Content Posting API.

2.6Liability

The tool is provided as-is, for the operator’s own use. The operator is solely responsible for the content it publishes and for compliance with each platform’s policies and applicable law.

2.7Changes to these terms

These terms may be updated as the tool’s functionality changes. The “Last updated” date at the top of this page reflects the most recent revision.
